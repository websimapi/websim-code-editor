# editor.js

## Purpose
Manages the code editor functionality, including tab switching, file content management, and editor interactions.

## Features
- Handles file content storage and retrieval
- Manages editor tabs and active file selection
- Updates line numbers dynamically
- Tracks cursor position for the status bar
- Provides code editing capabilities with tab insertion
